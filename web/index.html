METHOD · 03

          
不是黑盒：每个结论都有来路

          
比赛版优先保证稳定、可解释和可演示；数据层预留了替换为实时接口的位置。

        

      

      

        

          01
          
结构化市场卡

          
把关税、认证、渠道、买家与物流拆成字段，先约束事实，再生成文本，降低“看起来很像”的幻觉。

        

        

          02
          
可解释评分

          
需求 35% · 价格 25% · 渠道 15% · 竞争 15% · 合规 10%。分数不是结论，而是下一步动作的触发器。

        

        

          03
          
询盘规则解析

          
用实体抽取识别数量、价格、交期、认证与贸易条款，再把“价格 / 交期 / 信息缺口”转成跟进优先级。

        

        

          04
          
零依赖可运行

          
Python 标准库 HTTP 服务 + 原生前端，不依赖外部 API、数据库或密钥，现场断网也能完成演示。

        

      

      

        

          输入→市场卡检索→评分引擎→行动生成→询盘解析
